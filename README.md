# ses_weg

一个基于 [NoneBot2](https://github.com/nonebot/nonebot2) 的 QQ 机器人项目，提供丰富的图片处理、关键词回复、消息管理等功能。

## 功能特性

### 🖼️ 图片处理
- **图片变换**：支持对称、镜像、平移等多种几何变换
- **图像特效**：黑白、模糊、锐化、边缘检测、去噪
- **球形畸变**：放大镜/凸透镜/凹透镜效果，支持参数调节

### 🔑 关键词回复
- **自动关键词扫描**：根据文件夹名称自动生成关键词
- **手动关键词配置**：支持扩展和自定义关键词
- **图片/文本回复**：支持随机发送图片或文本内容
- **概率触发**：可设置触发概率
- **自动撤回**：支持延迟自动撤回消息

### 📦 消息管理
- **消息收集**：自动收集 Emoji、图片、文本消息
- **消息删除**：支持删除指定消息
- **黑名单管理**：关键词/用户黑名单功能

### 🛡️ 安全控制
- **全局守卫**：群组白名单控制
- **权限管理**：超级用户、管理员权限支持

### 🔧 系统功能
- **机器人重启**：支持手动重启命令
- **服务模块**：可复用的服务组件（黑名单、重启等）

## 主要插件说明

### a009_对称龙图 - 图片变换插件

支持多种图片变换效果：

**几何变换：**
- `对称左/右/上/下` - 将半部分翻转到另一半
- `镜像左/右/上/下` - 整图翻转后拼接（2倍大小）
- `平移左/右/上/下` - 半部分直接拼接

**图像处理：**
- `黑白` - 转为灰度图
- `模糊[参数]` - 高斯模糊（参数范围：0.5-10）
- `锐化[参数]` - 锐化增强（参数范围：0.5-5.0）
- `边缘检测` - 边缘检测效果
- `去噪[参数]` - 中值滤波去噪（参数范围：0.5-3.0）
- `放大镜/凸透镜/凹透镜/老花镜[参数]` - 球形畸变效果
  - 参数 < 1：向中心挤压（凹透镜）
  - 参数 > 1：中间放大（凸透镜）
  - 参数范围：0.1-5.0

**使用方法：** 回复图片消息，并输入变换命令（如：`对称左`、`模糊[2.5]`、`放大镜[1.2]`）

### a010_emoji_collect - 消息收集插件

自动收集回复消息中的图片和文本到指定文件夹。

**功能：**
- 自动识别回复消息中的图片和文本
- 根据关键词匹配目标文件夹
- 支持自动创建文件夹（`add <prefix> <token1> [token2] ...`）
- 自动撤回原始消息（可配置白名单群组）

### keyword_005_keywords_graph - 关键词图库

自动扫描文件夹并生成关键词触发器。

**特性：**
- 自动从文件夹名称提取关键词
- 支持手动扩展关键词
- 支持概率触发
- 支持自动撤回
- 支持图片和文本混合回复

### auto_002_global_guard - 全局守卫

控制机器人的访问权限。

**功能：**
- 群组白名单：只允许白名单内的群组使用
- 私聊控制：默认禁止私聊，超级用户除外

## 使用示例

### 图片变换

1. 发送一张图片
2. 回复该图片，输入：`对称左`
3. 机器人会返回对称后的图片

### 关键词触发

在群聊中发送关键词（如：`猫`），机器人会根据配置随机发送对应的图片或文本。

### 消息收集

1. 在群聊中发送关键词（如：`收集`）
2. 回复要收集的消息
3. 图片/文本会被自动保存到对应文件夹

## 开发说明

### 添加新插件

1. 在 `plugins/` 目录下创建新文件夹
2. 创建 `__init__.py` 和 `config.py`
3. 在 `__init__.py` 中实现插件逻辑
4. 使用 `PluginMetadata` 注册插件信息

### 服务模块使用

```python
from ses_weg.services import ban_list

# 加载黑名单
BAN_SET = ban_list.load_set()

# 添加黑名单项
ban_list.add(["关键词1", "关键词2"])

# 移除黑名单项
ban_list.remove(["关键词1"])
```

## 注意事项

- 请确保 `.gitignore` 正确配置，避免泄露隐私数据
- 不要将包含个人路径的配置文件提交到 Git

⚠️ **配置检查：**
- 检查代码中是否有硬编码的绝对路径
- 确保敏感配置文件（`.env`、`config.json`）在 `.gitignore` 中
- 数据文件（`data/`、`*.json`）应被忽略
